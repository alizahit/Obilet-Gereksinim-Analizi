# Obilet Gereksinim Analizi Projesi
Obilet markası için web sitesi ve mobil uygulama kullanıcı gereksinimlerinin tanımlandığı, resmedildiği ve senaryolarının oluşturulduğu Gereksinim Yönetimi dersi projesi.

## 📌 Proje Özeti
- **Proje Süresi:** 2023 Akademik Yılı
- **Use Case ve Kabul Kriterleri Sorumlusu:** Ali Zahit Kahraman
- **Ekip Büyüklüğü:** 5 kişi

## 🎯 Proje Amaçları
Bu proje, Obilet markası için bir gereksinim yönetimini(gereksinimlerin tanımlanması, resmedilmesi ve senaryolar oluşturulması) amaçlamaktadır.

## 🛠️ Katkıda Bulunduğum Alanlar
- **Use Case ve Kabul Kriterleri:** 
  - Use case diyagramı oluşturdum
  - Kabul kriteri belirledim
  - Use case formlarını doldurdum

## 📋 Fonksiyonel Gereksinimler
- Kullanıcılar hesap oluşturabilmeli
- Mevcut seferleri görüntüleyebilmeli
- Biletleri filtreleyebilmeli
- Banka/kredi kartı ile ödeme yapabilmeli
- 7/24 müşteri hizmetleriyle iletişime geçebilmeli

## 📊 Kabul Kriterleri Örnekleri
**Ad:** Ödeme işlemi
- Kriterler:
  - Ödemenin yapılabilmesi
  - Kartın kaydedilebilmesi
  - Bütün ödeme yöntemlerinin çalışması

**Ad:** Bilet inceleme
- Kriterler:
  - Araçlar hakkında gerekli bilgilerin gözükmesi
